# 浦发银行大厦外观精修

范围：世博大道909号，外观样板；标准层后续再做。
回退：v1.0-mvp（c9c06cd）；本轮在 refine/spdb-exterior 分支，本地预览，保留已发布基准。

## 参考与发现

[Aedas 官方项目](https://www.aedas.com/sc/project/shanghai-pudong-development-bank-new-office/) 及其 Hero / Pudong-Bank-1 / Pudong-Bank-3 实景照片（2026-11-06核对）。照片只作观察参考，临时存放，不纳入项目资源或纹理。

实景主要特征：高低两个直立体量，深色玻璃正面嵌入厚白色框架；主楼与附楼间为通高玻璃连接门厅；侧立面密集竖向白色肋片，顶部若干层为较通透的深色玻璃段；屋顶有蓝色浦发银行文字标识。首版的圆角盒子与连续横向突出楼板不符合这些特征。

## 实现决定

- 新建 src/spdb-exterior.js，独立生成该楼外观，不改变其他楼宇。
- 体量：80m示意总高（包括现有4m场地基座），低层附楼约30m；主体宽深由照片比例概括，不宣称测量尺寸。
- 建模白框、竖向肋片、细幕墙竖梃、水平细缝、门厅与屋面设备屏风；招牌使用程序绘制文字，图案与照片不复制为材质。
- 第二轮按用户反馈修正总图落位：参照远企大楼的主轴约40度，替换原来的负39度示意方向，并向范围内侧退让。点位、地块仍为示意，不声称已校准真实地籍。
- 主附楼独立分组，便于未来接入楼层示意；本轮不增加抽层UI、内部或室内家具。

## 验收

1. Node几何检查：三段主体独立；总高度不超过80m；几何非空、坐标有限；面数与绘制对象数受控。
2. npm test及静态构建通过。
3. 浏览器搜索定位浦发银行大厦，检查白框、主附楼与竖向幕墙；检查点击、昼夜与其他楼宇未被改动。
4. 保存本地样板截图，提供预览；此轮不覆盖GitHub Pages，待用户比较效果。

## 本轮验证结果

- 6项测试全部通过，静态构建通过。主附楼几何分离，总高在80m场地模型范围内。
- 浏览器已实际定位并查看近景，点击新增幕墙可正确选择浦发银行大厦；日景/夜景开关通过，错误与警告日志为空，当前桌面验收约60 FPS。
- 重复幕墙采用实例化几何，避免每根竖梃各占一个绘制调用。样板约43个几何绘制对象、4620个实例展开后的三角面（未计文字牌）。
- 点击浦发银行大厦时采用固定的主附楼观察方向，避免从上一座建筑继承的相机方向遮住附楼。
- 仅浦发银行的外观生成和描述发生变化，其他楼宇数据未改动。标准层未实现。
- 外观截图：`spdb-exterior.jpg`。实景比例的最终辨识效果仍需用户比较确认。

- 总图采用明确的40度轴线，并向核心范围内退让；避免等长轮廓边的选择导致模型翻转。
- 回归检查覆盖相邻轴线差小于3度、地块在核心边界内，以及全部模型顶点（包含实例化幕墙、台阶及雨蓬）在本楼地块内。
- 9项检查通过。单体与总图浏览器日志均无错误。截图见 spdb-exterior-revision2.jpg 和 spdb-layout-revision2.jpg。
