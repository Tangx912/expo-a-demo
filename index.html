ABOUT THIS MODEL

数据与操作说明

路网与 19 处楼宇轮廓来自 OpenStreetMap 官方二维数据。4 处缺失楼宇以公开地图街坊、地址与项目资料近似补充。建筑体块、立面与部分高度为示意，不能用于测量或规划审批。

附件 CAD 仅用于核对范围与路网，没有把附件中的建筑灰块直接当作实测建筑。未使用商业地图瓦片或受版权保护的建筑照片作为纹理。

左键拖动旋转、右键拖动平移、滚轮缩放。触屏单指旋转、双指缩放/平移。点击楼宇或列表定位；按 Esc 关闭详情；按 / 搜索。

完整来源与精度说明见项目 README 和各楼宇详情。无需运行时联网、账号或地图 API Key。
